# 桑多涅 Codex 自动适配版 0.7.0

Windows 11 x64。包含角色素材、1080p60 预渲染开屏、Node 和本项目预编译桥接模块；不包含官方 Codex、账号或微软 SDK。

1. 安装官方 Codex 并登录一次。
2. 本方案另需一次性安装微软 Windows SDK 的签名工具（MakeAppx）：https://developer.microsoft.com/windows/downloads/windows-sdk/ 。自行阅读并接受微软安装许可；本启动器不代装 SDK。不希望安装 SDK 时可选择同一发布页的 Windows 便携版。
3. 完整解压到本机可写目录，双击“安装快捷方式.cmd”。保存工作，正常退出 Codex（包括托盘），再从“桑多涅 Codex（自动适配）”进入。
4. 首次会自动核对官方来源与加载接口，生成当前版本的主题包。点击安装按钮，亲自确认 Windows 权限提示。以后从此入口启动，普通更新会自动准备新的适配包；安装仍需正常退出应用。

开屏支持重播，保持原官方 profile。已修复窗口模式下进度条与画面比例不一致；错误恢复按钮保留。真正的加载接口变化仍可能需要修代码，不能保证所有未来版本可用。普通官方图标不会执行自动适配步骤。

恢复：正常退出 Codex 后运行 Restore-Theme.cmd，只移除本项目主题附加包，保留官方程序、账号、聊天与 MCP。卸载附加包前不要直接删除目录。

代码和桥接模块采用 MIT；第三方代码、Node 及美术素材分别遵循 source 中的许可说明。游戏角色素材不因代码开源而获得额外授权。
