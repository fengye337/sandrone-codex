# Sandrone Codex 0.7.0

更新源码与下载包：窗口模式开屏布局修复、Windows 自动适配启动入口，以及实验性 macOS 社区支持。

## 下载选择

- **Windows-AutoTheme-x64.zip**：普通官方入口上的原生主题，沿用官方 profile，包含 1080p60 预渲染开屏、角色素材、手签、重播、加载进度和恢复。带 Node 与本项目桥接模块。需要一次性安装微软 Windows SDK 签名工具 MakeAppx，再运行“安装快捷方式.cmd”；退出 Codex 后从自动适配入口安装。普通更新自动准备精确目标包；真正接口变化仍可能需要维修。
- **Windows-x64.zip**：无需 SDK 的便携版，带 Node，保留独立 profile 和原开屏引擎。按包内 README 使用。
- **Source.zip**：全部源码与素材，Windows/Mac 共用一个仓库。Mac 使用 `Build-Mac.command` 构建完整主题与 Dock 启动器，或 `Build-Mac-Static.command` 构建 #6 的静态版。需要 Node 24+；完整版还需 Xcode Command Line Tools。

## 本次修复与整合

- 原生开屏的状态栏、进度条与视频统一使用居中的 16:9 画面坐标，窗口化、窄窗口和宽窗口不再分别按不同基准定位。错误恢复仍可点击。
- 自动适配不再要求维护者人工填写每个官方版本：启动时检查当前 Store 安装与加载契约，再生成匹配包；重复启动复用缓存，失败保留已有产物。主题代码更新也会刷新缓存。正常退出和 Windows 安装权限确认仍需本人操作，不强制关闭工作。
- 整合 wsqUsaqi537 的 #6 和 teddy7286317 的 #7，保留原始提交、署名、静态版入口及测试。Mac 文件主要独立，CDP 共用扩展保留 Windows 默认参数。

## 验证范围

维护侧 Windows 环境通过 75 项 Node 测试、六种窗口比例的真实浏览器布局/恢复测试及原生启动适配器回归。静态 Mac 路径在 Windows 审查环境中使用 POSIX 语义，避免平台默认分隔符导致误报。自动适配已在本机验证生成包、缓存复用、失败保留和安装预检。
