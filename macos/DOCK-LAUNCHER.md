# Dock 啟動、還原與移除（0.3.4 本地測試包）

這是獨立的桑多涅啟動器，不是官方插件，也不替換 ChatGPT。**日常使用不需要 Terminal 持續開著。** 主題與開屏會晚於官方視窗載入；只有從桑多涅啟動器啟動的本次程序才嘗試套用。**從官方 ChatGPT 圖示啟動不會自動套主題。** 本版仍待手動實機驗收，沒有公開發布。

## 放進 Dock

1. 保留目前可用的舊包。找到 `dist/Sandrone-ChatGPT-0.3.4-Mac-Test.app`，先把新包放到打算長期保留的位置，例如 Finder 的個人「應用程式」資料夾；本輪不自動安裝。
2. 從該固定位置將新包拖到 Dock 的應用程式區。也可啟動後在該圖示選「選項 → 保留在 Dock」。不要把官方 ChatGPT 圖示當成此啟動器。
3. 完成目前 Work 工作、儲存內容，手動 Cmd+Q 完全退出 ChatGPT。若有舊 Terminal 載入器，先 Ctrl+C 等待清理；若是舊 `.app`，先停用主題、手動退出 ChatGPT，再結束舊載入器。不要同時運行新舊載入器。
4. 點 Dock 中的桑多涅啟動器。它開啟自己的狀態視窗，並從 baseline 流程啟動 ChatGPT。這條路徑不開 Terminal、不開 early-document、不更改官方檔案或登入資料。
5. 等待「程式驗證通過，畫面仍待驗收」，再檢查實際畫面。這行只代表原版程式驗證通過，不等於介面全面驗收。設定、模型選單、普通啟動及錯誤恢復依 [手動驗收表](MANUAL-ACCEPTANCE.md) 記錄。

需要 macOS、建置時使用的 Node.js 24 以上版本。Node 執行檔仍是外部依賴，記在包內 `Contents/Resources/node-path.txt`；不是免依賴的公開發行包。若移除／搬動 Node，啟動器會顯示缺失訊息，需要保留可用 Node 並重新建置。移動 `.app` 本身不依賴原始碼位置。這是本機臨時簽名、未 Apple 公證的測試包；若系統阻擋，保留原狀並回報，不關閉 Gatekeeper／SIP 或其他系統防護。

## 視窗與 Dock 操作

| 操作 | 結果 |
|---|---|
| 關閉啟動器視窗 | 載入器繼續運行；不用開著 Terminal |
| 再點 Dock 圖示 | 重開狀態視窗，不再啟動另一個子程序 |
| 停用主題 | 請求目前擁有的載入器清理主題、重播 UI 與開屏媒體；查看清理是否已確認 |
| 重新啟用 | 本次載入器重新套用並驗證；不更改官方外觀偏好 |
| 重播開屏 | 排入本次重播請求；仍以實際畫面為準，原 header 的重播入口也保留 |
| 停止並清理 | 請求載入器停止監看並嘗試撤回，等待子程序結束；不退出 ChatGPT |
| 啟動器選單／Cmd+Q 結束啟動器 | 若載入器仍在運行，先等待停止與清理，再結束啟動器；不是強制退出 ChatGPT |
| 使用與還原說明／開啟診斷資料夾 | 開啟包內離線說明或此工具的本地資料夾 |

Dock 右鍵另提供顯示視窗、重播、停用、重新啟用及停止。按鈕和選單只傳送給自己的 Node 子程序，不從啟動器另外連接正在運行的官方程序。GUI 使用本次私有 stdio 通道；既有檔案控制命令仍保留供手動診斷。已從官方圖示啟動的 ChatGPT 不會被接管；啟動器會提示先儲存並退出。

停止後若要再次啟動，先手動完全退出仍在運行的 ChatGPT，再按啟動。僅關 ChatGPT 視窗可能不代表退出。若清理超過 10 秒，視窗會提示繼續等待或手動儲存、退出 ChatGPT；不會因此殺掉任何程序。清理「未能確認」不會標成已還原；若你原本要求結束啟動器，會取消這次退出並重開狀態視窗，讓你先看到提示。確認後可再次結束已停止的啟動器。

## 完整還原至官方使用方式

1. 在桑多涅啟動器按「停用主題」，檢查畫面；若載入器已失敗，不必反覆重試控制。
2. 按「停止並清理」，等顯示「載入器已停止」，再結束桑多涅啟動器。若清理未確認，仍繼續下一步。
3. 儲存工作並手動 Cmd+Q 完全退出 ChatGPT。**停止載入器不會關閉仍在該官方程序內的 loopback 除錯端點；完全退出 ChatGPT 才會關閉。** 本工具不替你強制退出。
4. 從官方 ChatGPT 圖示正常啟動，確認原生畫面。此時不會套用桑多涅主題。不需要重裝或修改官方包；若原先官方安裝本身異常，另由官方來源處理，本工具不修復或重簽它。

臨時出現白底淺字、內容消失、開屏擋住操作或任何錯誤時，先按停用；無法控制時，先儲存並手動完全退出 ChatGPT，再由官方圖示恢復。不要用刪官方 profile、清 cookie 或關系統防護來恢復。

## 移除本工具

完成上述還原、確定兩個應用及舊載入器都已結束後：

1. 從 Dock 選「選項 → 從 Dock 移除」。這只移除 Dock 捷徑。
2. 將你放置的 `Sandrone-ChatGPT-0.3.4-Mac-Test.app` 移至垃圾桶。舊版包和原始碼是否保留，由你決定；不要在仍有載入器運行時刪除它正在使用的檔案。
3. 可選：先備份想保留的診斷，再用 Finder「前往資料夾」檢視 `~/Library/Application Support/SandroneMacDev/`，移除此工具的資料夾。它含本工具的 state／logs；不是官方聊天或登入資料。若使用自訂 `SANDRONE_DATA_DIR`，只處理你指定的工具資料夾。
4. 保留 `/Applications/ChatGPT.app`、官方帳號資料、Keychain，以及其他工具需要的 Node.js。本工具沒有安裝登入項目、LaunchAgent、系統服務或官方包修改，不需要移除這些系統項目。

這輪不執行實機啟動或還原，由使用者手動操作及回報。未確認項目保持待驗收。
