# 0.3.4 手動實機驗收表

日期：2026-11-06。**以下均待使用者逐項回報**；程式測試、隔離 Chrome 和 Cocoa 假子程序測試不代替實機。已確認的對話／輸入框可讀、重播、停用／重啟用、首頁其他區域與窄視窗可讀性，以及 0.3.1 Chat／Work 原問題修復仍保留歷史確認，不擴大成新版全面通過。

先閱讀 [Dock、還原與移除](DOCK-LAUNCHER.md)，儲存工作、結束舊載入器並手動完全退出 ChatGPT。全程由使用者操作；代理不連線／操作受限應用。主題與開屏稍晚載入是已知限制，不以等待長度或動畫掩蓋。

| ID／項目 | 操作 | 預期與判定 | 狀態 |

## 願意分享的證據

使用者可自行分享不含帳號／私人對話的畫面、發生順序與下方回報。需要額外診斷時，才在相應畫面手動執行下列指令；Terminal 只用於這次可選診斷，不需要為日常運行保持開啟：

```sh
# 在倉庫根目錄；只有 .app 時可進入包內 Contents/Resources 執行
node macos/audit-current.mjs --manual settings
node macos/audit-current.mjs --manual menu
node macos/audit-current.mjs --manual disabled
node macos/startup-report.mjs
```

只在目前確實由本載入器啟動且仍運行時使用 audit。完整還原並從官方圖示重開後，舊 session 身份檢查應拒絕，**不要為收診斷重新開官方除錯端點**。結果位於工具資料夾的 `logs/manual-settings.json`、`manual-menu.json`、`manual-disabled.json`；摘要可自行保存。只分享你同意的檔案，不需要整份資料目錄或 state，代理不會代你操作。
